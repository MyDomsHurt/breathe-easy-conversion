# Breathe Easy — Conversion Dashboard

Calm interactive view of HubSpot contact velocity and conversion by acquisition stream.

## Live

Open **[index.html](index.html)** or enable GitHub Pages on this repo (Settings → Pages → Deploy from `main` / root).

Once Pages is on, the dashboard will be at:

**https://mydomshurt.github.io/breathe-easy-conversion/**

## What’s inside

- **Weekly Contact Flow (last 90 days)**  
  New contacts created each week vs how many of those already have a deal.

- **Conversion by Stream**  
  Contact → Customer (and Has Deal) rates over time for Instagram, Meta Ads, Referral, Website, etc.

Data snapshot: 12 Aug 2026. Built from a full HubSpot export for Breathe-Easyhk.
